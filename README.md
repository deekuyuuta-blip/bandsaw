# 帯鋸打音モニター

帯鋸の溶接部などにき裂が入ると、き裂部がガイドやホイールを通るたびに「カチッ」と鳴ります。
この音は帯鋸1周（全長 ÷ 鋸速度）ごとに繰り返すので、スマホのマイクで拾った音を周波数分析し、
帯鋸1周の周波数とその2倍に鋭い山が続いていないかを常時監視します。

**アプリ:** https://deekuyuuta-blip.github.io/bandsaw/ （Android の Chrome で開く）

## 構成

| パス | 内容 |
|---|---|
| `index.html` | スマホ用アプリ本体（1ファイル。`build.py` で生成） |
| `src/core.js` | 判定ロジック（フィルタ・FFT・スコア・帯鋸ごとの基準） |
| `src/ui.html` | 画面 |
| `build.py` | `src/` から `index.html` を作る |
| `python/` | PC 用の監視ソフト（カメラ RTSP・マイク・録画ファイル） |

## 2026/10/27 CAM9 録画での検証

| 時間帯 | 30秒平均スコア | 判定 |
|---|---|---|
| 11:57〜12:02 午前・切削中 | 最大 5.9dB | 発報なし |
| 12:58:53〜 昼休み明け、溶接部の割れの打音 | 上昇 | 12:58:59 警報 |
| 13:08:50 | | 破断（警報から約10分） |
| 15:27 交換後 | 最大 4.9dB | 発報なし |

## 判定

- 注意: 30秒平均 ≥ 8dB かつ 周波数の安定度 ≥ 0.7
- 警報: 30秒平均 ≥ 11dB（安定度 ≥ 0.7）、または 瞬時 ≥ 14dB が1.5秒続く
- 「帯鋸を交換した」で、その帯鋸の最初の10分を基準として学習し、以後は「固定値」と「基準＋上昇幅」の大きい方で判定

このアプリは補助的な予兆検知です。非常停止やカバーなどの安全装置の代わりにはなりません。
